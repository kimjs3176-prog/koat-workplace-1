# 실제 ERP 시험 순서 (🩺 진단 보고서)

서무비서 확장을 실제 ERP·그룹웨어에서 시험하고, 진단 보고서로 고칠 점을 찾는 순서입니다.
진단 기록에는 **입력한 값·초안 내용이 들어가지 않습니다**. 칸 이름·종류·프레임 위치·버튼 이름·동작 결과만 남습니다.

## 0. 준비 (5분)
1. 서무비서 웹 화면 **🧩 확장 설치**에서 새 확장(1.3.0 이상)을 받아 설치합니다. 예전 판이 있으면 `chrome://extensions`(엣지는 `edge://extensions`)에서 지우고 새로 '압축해제된 확장 프로그램을 로드'합니다.
2. 확장 아이콘 › 옆 패널 **⚙ 설정**에서 **ERP 주소**에 `https://kerp.koat.or.kr`이 들어 있는지 확인합니다(없으면 넣고 저장 → 권한 허용).
3. 옆 패널의 **🩺**를 눌러 진단 센터를 엽니다. **진단 기록 켜짐**인지 확인하고, 이전 기록이 있으면 **기록 지우기**를 누릅니다.
4. ERP 탭을 **새로고침**합니다(확장 설치 뒤 열려 있던 탭에는 확장이 붙지 않습니다).

## 1. 시험할 것 (화면마다 반복)
| # | 할 일 | 확인 | 진단 센터에서 |
|---|---|---|---|
| 1 | ERP 첫 화면 → 전자결재 → 기안(출장·휴가·여비정산 등) 화면 열기 | 패널이 그 업무 안내로 바뀌는지, ERP 화면 오른쪽 아래 🗂 버튼이 보이는지 | 화면을 연 뒤 **📸 화면 구조 기록** |
| 2 | 제목·본문 칸을 한 번씩 눌러 보기 | — | (자동 기록) |
| 3 | 패널에서 초안 만들기 → **📥 ERP에 넣기** | 제목·본문에 들어가는지, 다른 칸에 잘못 들어가지 않는지 | 안 되면 **메모**: "본문 편집기에 안 들어감" 등 |
| 4 | 🔧 ERP 맞춤 → 구조 분석 → 칸 연결 → 시험 채우기 → 내 규칙 저장 | 칸 목록에 제목·본문·기간 칸이 보이는지 | 안 보이는 칸을 **메모** |
| 5 | **상신(결재요청)** 버튼 누르기 — 실제 상신 전에 카드가 떠야 함 | 결재 전 점검 카드가 뜨는지 → **취소** 눌러 실제 상신은 하지 않기 | 카드가 안 뜨면 버튼 이름을 **메모** |
| 6 | 임시저장·미리보기 등 다른 버튼 | 카드가 뜨지 않아야 정상 | — |

> 실제 결재를 올리지 않으려면 5번에서 반드시 **취소**를 누르거나, 시험용 문서로 진행하세요.
> 이상한 점이 보이면 그때그때 진단 센터에 **메모 남기기**를 해 두면 분석이 훨씬 빨라집니다.

### 온나라(onnara.koat.or.kr) 공문 기안
> **IE 모드 주의(1.3.4)**: 온나라가 Edge **IE 모드**(주소창 왼쪽 'e' 아이콘)로 열리면 브라우저 확장이 화면 안에 들어갈 수 없습니다.
> 이때는 🗂 버튼·결재 전 점검 카드·📥 칸 채우기·📸 기록이 동작하지 않고, 확장은 **탭 주소·창 제목만으로** 업무를 알아봐 옆 패널에 안내를 띄웁니다.
> 초안은 패널에서 복사해 한글 기안기 본문에 **Ctrl+V** 로 넣으세요. 기관이 온나라를 일반(Chromium) 모드로 열 수 있게 하면 모든 기능을 쓸 수 있습니다.
- 확장 1.3.1부터 온나라도 기본 주소에 들어 있습니다(ERP의 '온-나라 결재' 메뉴로 열려도 동작).
- 기안(공문) 작성 화면을 열고 **📸 화면 구조 기록** → 패널이 '기안 결재' 안내로 바뀌는지 확인합니다.
- 제목 칸을 누르고 패널에서 기안문 초안 → **📥 ERP에 넣기**: 제목 칸에 들어가는지 봅니다. 본문(웹 한글 기안기)은 직접 넣을 수 없으면 **초안이 복사**되니 본문을 누르고 Ctrl+V 합니다.
- **결재올림(상신)** 버튼 → 결재 전 점검 카드가 뜨는지 확인 후 **취소**.
- 본문 편집기가 어떤 구조인지(웹 한글 기안기 등) 스냅샷이 있어야 본문 바로 넣기를 만들 수 있습니다 — 기안 작성 창(팝업)에서 꼭 📸를 눌러 주세요.

## 2. 보고서 보내기
- **⬇ 보고서 받기(.json)** → Claude 대화에 파일을 첨부하고 "진단 보고서 확인해줘"라고 합니다. 또는
- **☁ 서버로 보내기**(관리자 토큰) → 저장소 `diag/` 폴더에 커밋됩니다. Claude에게 "diag 폴더 보고서 확인해줘"라고 합니다.
- 간단히는 **📋 요약 복사**를 대화창에 붙여 넣어도 됩니다(메모·오류·못 알아본 화면·버튼만).

## 3. 분석 (개발 쪽)
```
python scripts/diag_report.py diag/            # 또는 받은 .json 파일 경로
```
| 보고서 항목 | 고치는 곳 |
|---|---|
| 못 알아본 화면의 문구 | `extension/config.js`의 `SEC_RULES`에 정규식 추가, 또는 🔧 ERP 맞춤 화면 규칙(기관 공유) |
| 가로채지 않은 상신 버튼 이름 | `extension/guard.js`의 `SUBMIT` |
| 못 찾은 칸(`how=못 찾음`) / 편집기 단서 | 화면 규칙의 칸 선택자(sel·id·name), 편집기 넣기(`content.js` `insertText`) |
| 확장이 붙은 프레임에 ERP 본문 프레임이 없음 | 다른 출처 프레임 → 설정의 ERP 주소에 그 주소 추가 |
| `panel.open` 실패·`frames.error` | 권한·주소 설정, 브라우저 정책 |
