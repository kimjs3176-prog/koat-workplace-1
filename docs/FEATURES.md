# 서무비서 기능 자세히

[← README](../README.md)

아래 기능은 확장의 옆 패널과 웹 화면에서 똑같이 쓸 수 있습니다(같은 서무비서 화면을 패널에 담음).

## 기본기능
| 기능 | 내용 |
|---|---|
| **상황으로 묻기** | "출장 다녀와서 정산해야 해요", "노트북 2대 사야 해요"처럼 입력하면 해당 절차를 찾습니다. 등록된 절차가 없으면 관련 규정 조문을 대신 보여 줍니다. |
| **업무별 절차 정리** | 단계마다 순서·시점·기한·필요 서류·결재선을 정리해 보여 줍니다. |
| **근거 확인** | 단계마다 📖 근거 조문을 펼치면 현행 내규 원문에서 해당 조문을 바로 불러옵니다. **전문에서 보기**를 누르면 원문이 열리고 그 조문으로 이동합니다. |
| **서식 찾기** | 📎 서식을 누르면 규정 원본의 해당 별지·별표 위치가 바로 열립니다. **서식·규정** 탭에서 627종 서식과 규정 원문을 검색할 수 있습니다. |
| **규정·서식 수정·삭제·추가** | 절차를 **공통 → 기관 → 개인 보충** 세 층으로 관리합니다(아래 '절차 관리'). 내규 원문은 `/upload`에서 개정·신규 등록합니다. |

## 선택기능
| 기능 | 내용 |
|---|---|
| **문서 초안** | 출장결과보고서·여비 정산·국외출장 귀국보고서·휴가 신청·물품 청구·법인카드 증빙·업무 인계 목록·기안문 본문·외부강의 신청. 입력하면 미리보기가 채워지고 복사하거나 텍스트로 저장합니다. |
| **다음 할 일·기한** | 출발일·마친 날 같은 기준일을 넣으면 "마친 날 다음 날부터 14일 이내" 같은 기한을 날짜와 D-day로 계산하고 다음 할 일을 짚어 줍니다. 기한은 **캘린더 파일(.ics)**로 받아 Outlook·구글 캘린더에 넣을 수 있습니다. |
| **결재선 정리** | 위임전결규칙 별표의 해당 항목을 안내하고, 부서에서 실제로 쓰는 결재선은 **개인 보충**에 적어 두면 절차를 열 때마다 함께 보입니다. |
| **층별 관리** | 공통 규정(기본 탑재) · 기관 규정(관리자 등록) · 개인 보충(내 브라우저)을 따로 관리합니다. |
| **처리 이력** | 체크한 단계·기준일·메모가 건별로 남습니다. 담당자가 바뀌면 이력 파일을 내보내 넘겨줄 수 있습니다. |

## 서무비서만의 기능
| 기능 | 내용 |
|---|---|
| **🗓 문장 속 날짜 인식** | "10월 5일부터 7일까지 출장 다녀왔어요", "어제", "다음 주 화요일", "10/5~10/7", "2박 3일"을 읽어 기준일을 자동으로 넣고 기한을 바로 계산합니다. |
| **⚠ 휴일 기한 보정** | 계산된 기한이 토·일·공휴일(대체공휴일·기관 휴일 포함)이면 앞 근무일을 함께 안내합니다. |
| **🚫 제출 전 반려 점검** | 절차마다 규정 조문에 근거한 '반려되기 쉬운 항목'을 결재 전에 확인합니다. 실제로 반려됐다면 **반려 사례 기록**을 남겨 다음 처리 때 점검 항목으로 보이게 하고, 관리자는 이를 기관 점검 항목으로 올립니다. 점검이 남은 채 완료하면 한 번 더 확인합니다. |
| **📝 근거 개정 감지** | 각 절차는 근거 규정의 확인 당시 개정 정보를 기억합니다. 규정이 개정·재업로드되면 해당 절차에 "근거 규정이 개정되었습니다 — 재확인 필요"를 표시합니다. |
| **⏰ 기한 경과 경고** | 기한이 지난 미완료 단계가 있으면 알려 줍니다. |
| **📅 업무 달력** | 처리 중인 모든 건의 단계 기한을 한 달 달력에 모아 보여 주고, 기한 지남·이번 주·다음 주 할 일을 정리합니다. 공휴일·기관 휴일이 표시되고, 전체 기한을 캘린더 파일(.ics)로 한 번에 받을 수 있습니다. **🗓 내 일정**(회의·교육 등)을 직접 넣거나, **메일의 일정 안내 글·초대장(.ics)·메일 파일(.eml)을 달력에 끌어다 놓아** 제목·날짜·시각·장소를 자동으로 채울 수 있습니다(해외 시간대 초대장은 한국 시각으로, Outlook 모임 요청 메일은 속의 초대장으로 읽고, 취소된 모임은 넣은 일정을 지울지 묻습니다)(확장: 글을 고르고 오른쪽 클릭 › 📅 서무비서 일정으로 추가). |
| **📖 규정 질의응답** | "경조사 휴가 며칠?", "숙박비 상한 얼마야"처럼 물으면 우리 기관 내규에서 관련 조문을 찾고(키워드 + 의미 검색), AI가 **그 조문 안에서만** 답합니다. 답에는 근거 조문(바로 열기·개정 정보)과 조문에서 그대로 옮긴 인용문이 붙고, 서버가 인용문이 실제 조문에 있는지 확인해 **확인되지 않으면 답을 보이지 않고** 관련 조문만 보여 줍니다. AI 키가 없으면 관련 조문 목록만 보입니다. |
| **🔗 일정 → 업무 연결** | 달력에 넣는 일정(직접 입력·메일·초대장)이 출장·교육·행사·휴가처럼 등록 절차와 맞으면 '업무로 연결'이 미리 체크됩니다. 저장하면 그 절차의 처리 건을 만들어 일정 날짜를 기준일로 넣고, 사전 신청·사후 정산 같은 **기한을 달력·이번 주 할 일·확장 알림에 올립니다**. 일정 날짜를 고치면 처리 건의 기준일도 따라갑니다. |
| **🧾 영수증 사진 인식** | 승차권·숙박 영수증·카드 전표 사진을 올리면 AI가 날짜·금액·가맹점·종류·결제수단을 읽습니다. 읽은 값으로 **기준일을 채우고**, 여비 정산 초안의 운임·숙박비 합계와 증빙 목록을 채우며, **증빙 점검**(운임·숙박 증빙 누락, 출장 기간 밖 영수증, 법인카드 미사용)을 자동으로 보여 줍니다. AI 키가 없으면 사진을 붙이고 직접 입력합니다. |
| **✦ AI 상황 이해** | 등록 절차에 없는 표현이나 "해외 가서 세미나 열어요"처럼 여러 업무가 섞인 문장을 이해해, 필요한 절차를 **처리 순서대로** 묶어 안내합니다. AI는 등록된 절차 가운데서만 고르고 규정 내용을 지어내지 않습니다. 여러 업무가 이미 등록 절차와 맞으면 AI 없이도 묶어 보여 줍니다. |
| **📄 한글(.hwpx) 초안** | 문서 초안을 한글 파일로 내려받습니다. 기관 서식이 있으면 `secretary/template.hwpx`로 바꿔 넣을 수 있습니다. |

## 결재 전에 막아 주는 기능 — 누구나 만드는 '규정 검색'과 다른 점
| 기능 | 내용 |
|---|---|
| **🔍 결재 전 사전 감사** | 결재를 올리기 전에 이 건의 기준일·체크·증빙·초안을 규정과 대조합니다. **규칙 감사**(항상 동작)는 기한 경과·임박, 숙박비 1박 상한(서울 10만·광역시·제주 8만·그 밖 7만 원, 부득이한 경우 30% 추가)과 추가지급 한도 초과, 법인카드 외 결제, 운임·숙박 증빙 누락, 출장 기간 밖 영수증, 초안 필수 항목 누락을 잡습니다. AI 키가 있으면 **AI 감사관**이 절차·사실관계·초안을 근거 조문 원문과 대조해 더 찾습니다. 모든 지적에는 📖 근거 조문이 붙고, 근거 조문을 대지 못한 AI 지적은 '참고'로만 보입니다. '높음' 지적을 확인하지 않고 완료하면 한 번 더 묻습니다. |
| **🔬 규정 개정 영향 분석** | 개정본을 `/upload`로 올리면 이전본과 **조문 단위로 비교**해 내용 개정·번호 이동·신설·삭제를 찾고, 그 조문을 근거로 쓰는 **절차 단계·반려 점검 항목**을 짚습니다. "제15조 → 제16조", "기한 14일 → 10일"처럼 **고칠 안을 자동으로 만들고**(AI 키가 있으면 단계 문장 갱신안도), 관리자가 골라 **한 번에 기관 층에 반영**합니다. 반영하면 '재확인 필요' 알림이 사라집니다. |
| **👥 기관 집단 지식** | 담당자들이 완료한 건의 **익명 숫자**(완료까지 걸린 일수, 기한을 넘긴 단계, 사전 감사에서 걸린 항목 종류)를 모아 "완료까지 보통 6일 · 6단계에서 40%가 기한을 넘김"처럼 다음 담당자에게 돌려줍니다. 반려를 겪은 담당자가 **직접 공유를 고른 반려 사유**는(이름·전화번호·금액은 지워서) 다른 담당자의 점검 항목에 '기관에서 N회 반려'로 보이고, 관리자는 이를 기관 점검 항목으로 올립니다. 표본이 3건 이상일 때만 통계를 보이며, 처리 이력 화면에서 기여를 끌 수 있습니다. |

## ✦ AI 결과는 사람이 확인해야 문서로 — 산출물 기록과 월별 보고
AI는 기존 업무의 일부(영수증 읽기·감사 지적·보고서 문장 초안)에서 **검증할 수 있는 결과**를 만들고, 담당자가 확인한 것만 문서 산출물에 들어갑니다.
| 기능 | 내용 |
|---|---|
| **✦ AI 문서 초안** | 출장결과보고서 '주요 내용'·국외출장 귀국보고서 '주요 활동' 칸의 **✦ AI 초안** — 이 건의 메모·일정·처음 적은 상황·기준일·증빙에 **적힌 사실로만** 줄을 만들고 **줄마다 근거 자료**(← 이 건 메모 등)를 붙입니다. 서버가 줄마다 근거 표시, 숫자가 근거 자료에 있는지, 줄의 내용 말(협의·확인 같은 틀 말 제외) 60% 이상이 근거 자료에 있는지 확인해, 확인되지 않은 줄(예: 자료에 없는 '3억 원')은 채우지 않고 따로 보여 줍니다. 담당자는 고친 뒤 **✓ 확인** 또는 **✕ 버리기**(원래 내용으로). 서식의 칸에 `"ai": true`를 붙이면 다른 초안에도 켜집니다. |
| **✓ 사람 확인** | AI가 읽은 영수증 값은 **확인 대기**로 들어와 증빙 카드의 **✓ 확인**을 눌러야 '사람 확인'이 됩니다(확인 뒤 고치면 '고쳐서'로 바뀜). 초안 창은 AI 값이 든 칸에 '확인 대기' 표시를 하고, **확인 대기인 AI 결과가 든 채 복사·한글·ERP 넣기를 하면 한 번 더 묻습니다**(확인하면 확인한 것으로 기록하고 내보냄). AI 감사 지적은 **✓ 확인·조치함 / ✕ 해당 없음**으로 판단을 남깁니다. |
| **📊 AI 산출물 기록·월별 보고** | 건마다 'AI 결과(영수증 인식·감사 지적·문서 초안)를 그대로 썼는지·고쳤는지·버렸는지'와 낸 문서(AI 반영 여부)를 처리 이력에 남겨 인계됩니다. 관리 화면의 **✦ AI 산출물 보고(월별)**는 기관 전체(집단 지식 저장소가 있을 때, 익명 숫자) 또는 이 브라우저 기준으로 월별 'AI 결과 · 그대로 · 고쳐서 · 버림 · 대기 · 낸 문서(AI)'를 보여 주고, **📋 보고 문구**로 월간 실적 문장을 복사합니다. 내용·금액은 보내지 않고, 처리 이력 화면에서 기여를 끌 수 있습니다. |

## 📄 한글 서식 작성 — 출장복명서·여비 정산·기안문 (kordoc)
초안 창의 **한글 서식** 줄에서 바로 한글 파일(.hwpx)을 만듭니다. 서식 엔진은 공공문서용 오픈소스 [kordoc](https://github.com/chrisryugj/kordoc)(MIT)입니다.
| 버튼 | 결과 |
|---|---|
| 📄 공문 서식(.hwpx) | 입력한 항목으로 공문 '보고서' 서식을 만듭니다(제목, 구분·내용 표, □ 항목과 가·나 번호, 맺음말). |
| 📑 간이기안문 | 표준 간이기안문(결재란·제목·요약·작성일·작성기관)에 채웁니다. |
| 📂 우리 서식에 채우기 | 우리 기관의 출장복명서 같은 **.hwpx 서식**을 올리면 **칸 이름(표의 라벨·누름틀)**을 찾아 값을 넣습니다. 원본 서식은 그대로 유지되고, 올린 서식은 이 브라우저에 기억돼 다음부터 한 번에 채웁니다. 칸 이름이 달라도 흔히 쓰는 이름(성명·출장자, 기간·출장기간 등)은 알아봅니다. |

- 서버에 Node 20 이상과 `npm ci`(kordoc)가 필요합니다. Vercel은 `api/forms.mjs`(Node 함수)로 자동 배포되고, Docker 이미지에도 포함되어 있습니다.
- kordoc이 없는 서버에서는 예전처럼 내장 기본 서식(📄 한글(.hwpx))으로 만듭니다.

## 🧩 브라우저 확장 — 메인 (`extension/`, Chrome·Edge)
| 기능 | 내용 |
|---|---|
| 옆 패널 | 도구 모음 🗂·**Alt+Shift+S**·ERP 화면의 🗂 버튼으로 엽니다. ERP 화면을 알아보면 **그 업무 안내가 바로** 열립니다(설정에서 끌 수 있음). |
| 🚫 결재 전 점검 | ERP에서 **상신·결재요청·기안·제출** 버튼을 누르면 그 업무의 반려 점검 항목(근거 조문 포함)을 먼저 보여 줍니다. 확인하고 '계속'을 누르면 원래 버튼이 그대로 눌립니다(10분간 다시 묻지 않음). 임시저장 같은 다른 버튼은 건드리지 않습니다. |
| 🔎 입력값 점검 | 결재 전 점검 카드가 열릴 때 **ERP 화면에 입력된 값**(출장 기간·사용일·근무 시각·첨부 수)을 읽어, 날짜 기한(예: 출장 마친 날 다음 날부터 14일 안 정산, 휴가 시작 전 등록, 출국 10일 전 제출)·하루 시간외 4시간·공동근무시간·첨부 누락 항목에 ✓/⚠와 이유를 붙이고 걸린 항목을 맨 위로 올립니다. 작성일·결재일 칸은 빼고, 기간 앞뒤가 바뀌었으면 경고합니다. 읽은 값은 판정에만 쓰고 저장·전송하지 않습니다(규칙: 절차 데이터의 반려 점검 항목 `check`). |
| 📥 ERP에 넣기 | 서무비서 초안을 ERP에서 **마지막으로 누른 입력란**에 넣습니다. 넣을 수 없는 편집기(웹 한글 기안기 등)는 복사해 두니 Ctrl+V 하세요. |
| 🩺 진단 | **자동 진단**(IE 모드·주소 설정·못 알아본 화면·상신 버튼 후보·오류를 조치와 함께 정리), **이 탭 점검**(확장이 붙었는지·권한·알아본 업무), 화면 구조 기록·보고서 보내기 |
| ✦ AI 분석 | 상황을 문장으로 말하면 맞는 절차·고른 이유·읽은 내용·더 확인할 점·조심할 반려 점검 항목을 안내합니다. 기관 키(`ANTHROPIC_API_KEY`/`GEMINI_API_KEY`)가 없으면 **내 AI 키**(이 브라우저에만 저장, 서버 저장 안 함)로 켭니다. |
| ⏰ 기한 알림 | 처리 중인 건의 기한을 받아 **도구 모음 아이콘 배지**(지난 기한 빨강·2일 안 주황)와 **오늘·내일 기한 바탕화면 알림**을 띄웁니다. 알림이 한 건의 기한이면 누를 때 **그 건이 바로 열립니다**(웹 주소 `?case=`). |
| 묻기 | ERP 글자 드래그 → 오른쪽 클릭 '서무비서에 묻기', 주소창에 `서무` + 띄어쓰기 + 상황(치는 동안 맞는 절차 이름을 제안) |
- **설치**: 웹 화면 **🧩 확장 설치** 탭에서 받습니다. 이 서버 주소와 기관 ERP 주소(⚙ 기관 설정 › ERP·그룹웨어 주소)가 미리 들어 있습니다. 명령으로 만들려면 `python scripts/build_extension.py --server https://<서무비서 주소>`.
- 웹 화면은 확장이 설치되어 있는지 알아보고, 설치되어 있으면 설치 안내 대신 'ERP에서 쓰세요'를 보여 줍니다.
- **실제 ERP 시험**: 패널의 🩺 진단 센터에서 화면 구조·동작 기록을 보고서로 받아 `scripts/diag_report.py`로 분석합니다([docs/ERP_TEST.md](ERP_TEST.md)).
- 설치·배포·진단 자세히: [extension/README.md](../extension/README.md)

## 다른 기관에서 쓰기(호환성)
코드 수정 없이 **기관 설정 · 우리 내규 · 규정명 매핑**만으로 도입합니다. 자세한 순서는 [docs/ADOPTION.md](ADOPTION.md)를 보세요.
- **기관 설정**(`secretary/config.json`, 화면에서 편집): 기관명·서비스 이름·대표 색·아이콘, 절차 문장의 기관별 명칭(`[[erp]]`→"통합정보시스템" 등), 기관 휴일
- **🧩 ERP 화면 규칙**(기관 설정 › ERP 화면 규칙): 어떤 ERP·그룹웨어든 코드 수정 없이 맞춥니다. **바탕 묶음**(일반 · KOAT ERP·온나라 · 더존 Bizbox·iCUBE · 온나라 문서관리 · SAP — `secretary/erp_presets.json`, '검증 전' 묶음은 출발점)을 고르고, 그 위에 기관 맞춤 규칙을 더합니다: **제출 버튼 이름**(이름 전체가 같을 때만 결재 전 점검), **화면 규칙**(`주소:정규식` 또는 `제목:정규식` => 절차 id), **업무 화면이 아닌 주소**, **입력값 점검 칸 이름**(시작·끝·제외). 저장하면 모든 사용자의 확장이 30분 안에 받고, 기관 맞춤 확장(zip)에도 미리 들어가 서버에 닿지 않을 때도 동작합니다. ERP에서 확장 🩺 진단 센터의 **🧩 ERP 규칙 제안**(가로채지 못한 제출 버튼·못 알아본 업무 화면을 같은 형식으로 정리)을 복사해 붙여 넣으면 됩니다. 입력값 점검은 라벨·aria·표 머리칸·div 격자·연/월/일 선택칸·보기 화면 글·'A ~ B' 한 칸 기간을 읽습니다.
- **규정명 매핑**: 절차가 가리키는 규정명을 우리 기관 규정에 연결합니다(매핑 → 정확 일치 → 기관명 접두어 → 근사 연결 순으로 자동 연결, 근사는 '확인 필요' 표시).
- **🩺 호환성 점검**: 연결 안 된 근거·서식, 근거 규정 개정, 우리 규정으로 확인 전인 절차를 한눈에 보여 줍니다.
- **📦 절차 팩**: 절차를 표준 JSON(`secretary/schema/`)으로 내보내고 가져옵니다. 가져오기 전에 우리 규정 연결 여부를 미리 보여 줍니다.
- **일괄 등록·배포**: `scripts/import_regs.py`(내규 폴더 일괄 등록), `Dockerfile`(기관 내부 서버), `.env.example`
