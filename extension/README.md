# 서무비서 브라우저 확장 (Chrome · Edge)

ERP·그룹웨어(기본: `https://kerp.koat.or.kr`) 화면 **옆 사이드 패널**에서 서무비서를 쓰는 확장입니다. Manifest V3 형식이며, 같은 파일로 Chrome과 Edge에서 모두 동작합니다.

| 기능 | 내용 |
|---|---|
| 🗂 사이드 패널 | 도구 모음 아이콘이나 **Alt+Shift+S**로 엽니다. ERP 화면을 그대로 둔 채 오른쪽에서 절차·기한·서식·근거·사전 감사를 봅니다. |
| 화면 감지 | ERP에서 출장·여비 정산·휴가·법인카드·지출결의·구매·기안 같은 화면을 열면 오른쪽 아래 **이 업무 안내 보기**가 뜨고, 패널 위에도 같은 제안이 나옵니다. 판단에는 화면 제목 문구만 씁니다. |
| 📥 ERP 입력란에 넣기 | 서무비서에서 초안을 만든 뒤 ERP의 본문이나 제목 칸을 한 번 누르고 이 버튼을 누르면, 그 칸에 들어갑니다. iframe 웹 편집기도 지원하고, 한 줄 칸에는 첫 줄(제목)만 넣습니다. 칸을 찾지 못하면 클립보드에 복사해 두니 Ctrl+V로 붙여 넣으세요. |
| 오른쪽 클릭 | ERP에서 글자를 드래그한 뒤 **서무비서에 묻기**를 누르면 그 내용으로 안내합니다. |
| 🔧 ERP 맞춤 | 어떤 ERP·그룹웨어든 맞출 수 있습니다. 패널 위 🔧에서 **이 화면 구조 분석**을 누르면 모든 프레임의 입력란·편집기·제목을 찾고, 이름이 맞는 칸은 초안 항목과 자동으로 연결해 둡니다. 👁로 위치 확인, 🎯로 화면에서 직접 고르기, ▶로 시험 채우기를 한 뒤 저장합니다. 저장한 화면 규칙은 화면 감지와 **📥 ERP에 넣기(여러 칸 한 번에)**에 쓰입니다. |

## 설치

**가장 쉬운 방법** — 서무비서 화면의 **🧩 ERP 확장** 탭에서 받습니다. 이 서버 주소와 기관 ERP 주소(⚙ 기관 설정 › ERP·그룹웨어 주소)가 미리 들어 있고, 브라우저별 설치 순서가 나옵니다.

**시험(개발자 모드)**
1. `chrome://extensions`(Edge는 `edge://extensions`)에서 **개발자 모드**를 켭니다.
2. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 `extension/` 폴더를 고릅니다.
3. 설정 화면이 열리면 **서무비서 주소**(https)를 넣고 저장합니다.

**기관 배포본**
```bash
python scripts/build_extension.py --server https://<서무비서 주소> --erp https://kerp.koat.or.kr --version 1.0.0
```
- `dist/secretary-extension-1.0.0.zip`이 만들어집니다. 서무비서 주소와 ERP 주소가 미리 들어 있어 사용자가 따로 설정하지 않아도 됩니다.
- 이 zip을 Chrome 웹 스토어 또는 Edge 추가 기능(Partner Center)에 **비공개·조직 한정**으로 올립니다.
- 그룹 정책 `ExtensionInstallForcelist`로 기관 PC에 일괄 설치할 수 있습니다.

## ERP 화면 규칙(🔧 ERP 맞춤)
- **화면 규칙**: '주소에 들어 있는 글자'와 '화면 제목 글자' 중 하나 또는 둘 다(`/정규식/` 가능). 맞으면 그 화면의 업무 안내를 띄우고 칸 연결로 초안을 넣습니다.
- **칸 연결**: 칸마다 프레임 위치, 선택자, id·name, 칸 이름을 함께 저장합니다. 그래서 화면이 조금 바뀌어도 다시 찾습니다. 다시 찾는 순서는 선택자 → id → name → 칸 이름입니다.
- **연결할 수 있는 항목**: 제목(초안 첫 줄), 본문 전체, 그 초안의 각 항목(출장기간·출장지 등)
- **저장 위치**
  - 내 브라우저: `chrome.storage.local`
  - 기관 공유: 서무비서 서버 `secretary/erp_profiles.json`(관리자 토큰, GitHub 연동 시 커밋)
  - 같은 화면이면 내 브라우저 규칙이 우선합니다.
- **내보내기·가져오기**: JSON 파일로 부서·기관끼리 주고받을 수 있습니다.
- **개인정보**: 저장하는 것은 칸의 위치와 이름뿐이고, ERP 화면에 적힌 내용은 저장하지 않습니다.

## 다른 ERP·그룹웨어에서 쓰기
- 설정 화면의 **ERP 주소**에 한 줄씩 추가하면, 저장할 때 브라우저가 그 사이트 접근 허용을 묻습니다.
- 배포본에는 `--erp`로 넣습니다.
- 화면 감지 문구(어떤 제목이면 어떤 업무인지)는 `config.js`의 `SEC_RULES`에서 고칩니다.

## 서버 쪽 요구사항
- 패널은 서무비서 웹을 iframe으로 담습니다. 서버가 확장 페이지의 iframe을 허용해야 합니다.
  - Vercel 배포는 `vercel.json`에 `Content-Security-Policy: frame-ancestors 'self' chrome-extension: extension:`이 들어 있습니다.
  - 기관 내부 서버 앞단(nginx 등)에서 `X-Frame-Options: SAMEORIGIN`을 붙이고 있다면, 같은 `frame-ancestors` 정책으로 바꿔야 합니다.
- Vercel 미리보기 주소처럼 로그인 보호가 걸린 주소는 패널에서 열리지 않을 수 있습니다. 운영(Production) 주소를 쓰세요.

## 개인정보
- 확장은 ERP 화면의 **제목 문구로 업무 종류만** 판단하고, ERP 내용은 어디에도 보내지 않습니다.
- 초안을 ERP 입력란에 넣는 일은 이 PC의 브라우저 안에서만 일어납니다.
- 패널 안의 처리 이력·개인 보충은 **패널 전용 저장 공간**(이 브라우저)에 남습니다. 브라우저 정책상 일반 탭에서 연 서무비서와는 따로 저장됩니다. 옮길 때는 처리 이력 › 내보내기·가져오기를 쓰세요.

## 파일
| 파일 | 역할 |
|---|---|
| `manifest.json` | 권한: 사이드 패널·저장소·오른쪽 클릭 메뉴·스크립트 등록, ERP 주소 |
| `background.js` | 패널 열기, 화면 감지 결과 중계, 초안 넣기(마지막으로 누른 프레임으로 전달), 추가 ERP 주소 등록 |
| `content.js` | ERP의 모든 프레임에서 동작: 화면 감지, 입력란 기억·넣기, 🗂 버튼(Shadow DOM으로 ERP 화면과 격리) |
| `sidepanel.*` | 서무비서 웹을 `?embed=ext`로 담고, 메시지 출처(origin)를 확인해 주고받음 |
| `options.*` | 서무비서 주소·ERP 주소·🗂 버튼 설정 |
| `erp.*` | 🔧 ERP 맞춤 도구: 구조 분석, 칸 연결, 시험 채우기, 저장·공유·내보내기 |
| `config.js` | 기본값과 화면 감지 규칙(배포 스크립트가 기관 값으로 교체) |

> 사이드 패널 API가 없는 브라우저에서는 오른쪽에 작은 창으로 열립니다.
