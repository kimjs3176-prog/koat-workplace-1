🗂 서무비서 확장 설정

ERP·그룹웨어 화면 옆에서 서무비서를 엽니다. 설정은 이 브라우저 계정에 저장됩니다.

🩺 실제 ERP 시험 중 문제를 기록·보고하려면 진단 센터를 여세요(패널 위 🩺 버튼과 같음).

사용법
· 도구 모음의 🗂 아이콘(또는 Alt+Shift+S)을 누르면 오른쪽에 서무비서가 열립니다. 주소창에 서무 + 띄어쓰기 + 상황(예: 서무 출장 정산)을 입력해도 됩니다.
· ERP에서 출장·휴가·지출결의 같은 화면을 열면 🗂 버튼 위에 이 업무 안내 보기가 나타납니다.
· ERP의 글자를 드래그하고 오른쪽 클릭 → 서무비서에 묻기.
· 서무비서에서 초안을 만든 뒤 📥 ERP에 넣기를 누르면, 연결해 둔 칸들에 한 번에(연결이 없으면 마지막으로 누른 칸에) 들어갑니다.
· 어떤 ERP든: 패널 위 🔧 ERP 맞춤 → 이 화면 구조 분석 → 칸을 초안 항목과 연결해 저장합니다. 관리자가 '기관 전체에 공유'하면 모든 직원 확장이 받아 씁니다.

개인정보 — 확장은 ERP 화면의 제목 문구로 업무 종류만 판단하며, ERP 내용을 서버로 보내지 않습니다. 처리 이력은 서무비서 패널 안(이 브라우저)에만 저장됩니다.
