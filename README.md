# 🗂 KOAT 서무비서

ERP·그룹웨어 옆에서 일하는 서무 비서입니다. 출장·물품·행사·복무·결재 같은 서무 업무를 담당자가 일하는 자리에서
**절차 확인 → 할 일·기한 → 문서 초안·ERP 입력 → 상신 전 반려 점검**까지 돕습니다.

- **브라우저 확장(Chrome·Edge, 메인)**: ERP 옆 사이드 패널. 화면을 알아보고 그 업무를 안내하고, 상신 버튼을 누르면 반려 점검 카드를 띄웁니다.
- **웹 화면(보조)**: 상황을 문장으로 입력해 안내받고, 업무 달력·처리 이력·관리 기능을 씁니다. 확장 없이도 모든 안내 기능을 쓸 수 있습니다.

> 시작하기: 웹 화면의 **🧩 확장 설치**에서 우리 기관용 확장을 받아 설치합니다(약 1분).

## 무엇을 하나
| | |
|---|---|
| **절차 안내** | "출장 다녀와서 정산해야 해요"처럼 물으면 절차·서식·결재선과 📖 근거 조문(현행 내규 원문)을 보여 줍니다. |
| **기한 계산** | 문장 속 날짜("10월 5일부터 7일까지", "어제")를 읽어 단계별 기한·D-day를 계산하고, 휴일이면 앞 근무일을 알려 줍니다. 업무 달력·.ics·확장 알림. |
| **문서 초안** | 출장결과보고서·여비 정산·기안문 등 초안을 채워 복사·한글(.hwpx)·ERP 입력란에 넣습니다. |
| **지출결의서** | 🧾 지출결의서 탭: 일반·여비·업무추진비 ERP 본문을 만들어 복사·한글(.hwpx)로 받고, 여비는 증빙 사진에서 금액·일자를 읽어(브라우저 OCR) 출장 증빙 서식(Excel)을 채웁니다. |
| **반려 방지** | 결재 전 반려 점검 항목, 규칙·AI 사전 감사(기한·숙박비 상한·증빙·필수 항목), ERP 입력값 점검. |
| **규정 관리** | 내규 업로드·개정 영향 분석(바뀐 조문 → 고칠 절차 단계), ALIO 공시 내규와 자동 비교. |
| **규정 질의응답** | 내규 조문 안에서만 답하고, 인용문이 조문에 실제로 있는지 서버가 확인합니다. |

기능 설명 전체: [docs/FEATURES.md](docs/FEATURES.md)

## AI는 이렇게 씁니다
AI는 업무의 일부(영수증 읽기, 감사 지적, 보고서 문장 초안, 절차 고르기, 규정 답변)에서 **근거를 확인할 수 있는 결과**를 만들고, **문서로 나가기 전에 사람이 확인**하게 합니다.
- AI가 읽은 영수증 값과 AI 초안은 '확인 대기'로 들어오고, 확인하지 않은 채 내보내려 하면 한 번 더 묻습니다.
- AI 초안은 이 건의 메모·일정·증빙에 적힌 사실로만 쓰고 줄마다 출처를 붙입니다. 근거를 확인하지 못한 줄은 넣지 않습니다.
- 사람이 그대로 썼는지·고쳤는지·버렸는지를 건마다 기록하고, 관리 화면에서 **월별 AI 산출물 보고**로 봅니다.
- AI 키가 없으면 AI 기능만 꺼지고 나머지는 그대로 동작합니다.

## 데이터
- 처리 이력·개인 메모는 **사용자 브라우저에만** 저장됩니다(처리 이력의 ⬇ 내보내기로 보관·인계).
- 기관 통계에는 이름·금액·내용 없이 **익명 숫자만** 보내며, 처리 이력 화면에서 끌 수 있습니다. 단, 반려 사유는 담당자가 공유를 직접 고를 때만 문장을 보냅니다(이름·전화번호·금액은 지워서, 다른 담당자에게 보임).
- 영수증 사진은 서버에 저장하지 않습니다(AI 키가 있으면 인식을 위해 AI 공급자로 전송).

> 업무 참고용입니다. 최종 판단은 규정 원문과 담당 부서 확인을 거쳐 주세요.

## 실행
```bash
pip install -r requirements.txt
npm ci                  # 선택: 한글 서식 작성(kordoc, Node 20+)
python run_local.py     # http://localhost:5100
```
- `main`에 병합하면 Vercel이 자동 배포합니다. 기관 내부 서버는 `Dockerfile`.
- 주요 환경변수: `REG_UPLOAD_TOKEN`(관리 저장), `ANTHROPIC_API_KEY`·`GEMINI_API_KEY`(AI), `GITHUB_TOKEN`·`GITHUB_REPO`(읽기 전용 배포에서 저장), `UPSTASH_REDIS_REST_URL`·`UPSTASH_REDIS_REST_TOKEN`(기관 통계). 전체 목록은 [docs/ADMIN.md](docs/ADMIN.md#환경변수), 예시는 `.env.example`.
